# C Systems Programming Basics

Raccolta di esercizi e programmi sviluppati in C durante il percorso universitario di Ingegneria Informatica.

L'obiettivo della repository è consolidare concetti fondamentali di programmazione procedurale e gestione della memoria.

## Argomenti trattati

- Puntatori
- Stack vs Heap
- Allocazione dinamica (malloc, free)
- Strutture dati semplici (liste collegate, stack)
- Organizzazione modulare del codice

## Compilazione

Esempio:

gcc file.c -o program
./program

## Contesto

Progetti sviluppati in ambito accademico e riorganizzati in modo strutturato per documentare il percorso di apprendimento.
